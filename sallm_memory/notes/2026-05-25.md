  kwargs because `xLSTMForCausalLM.forward` has `**kwargs`. The model ignores

  improving; they are not catastrophic.

## Architecture-comparison thesis framing and literature pass

- User context to preserve: the master's project is an architecture comparison
  for South African languages. The intended contribution is to establish a
  reproducible South African baseline/comparison where the same corpus,
  tokenizer, task suite, parameter scale, and adaptation regimes are used to
  compare model families.
- Wording nuance:
  - Strong defensible claim: there does not appear to be a modern controlled
    South-African-language comparison of decoder-only Transformer, SSM/Mamba,
    xLSTM/RNN-style, and related efficient LM architectures trained and
    evaluated under the same setup.
  - Too-strong claim: "no architecture comparison exists at all." Crous and
    Buys (2021) compare n-gram, feedforward neural, RNN, and Transformer
    language models for low-resource South African languages on small-scale
    datasets.
- Current architecture set remains useful:
  - LLaMA-style decoder-only Transformer: essential reference baseline.
  - Mamba/Mamba-2: essential efficient SSM comparison, but final claims must
    distinguish HF implementation/config weakness from Mamba as a family.
  - xLSTM: high-priority recurrent/efficient architecture currently being
    tested; literature supports it as a serious Transformer/Mamba alternative.
- Strongest additional candidate if compute and implementation time allow:
  - HGRN2 / BabyHGRN. BabyHGRN is directly framed around sample-efficient
    low-resource language modeling and compares HGRN2 against Transformer,
    LSTM, xLSTM, and Mamba. It is the best "missing" architecture candidate
    for the thesis if we can make a 125M-ish implementation run.
- Secondary/future candidates:
  - RWKV: mature recurrent/linear-attention family with efficient inference and
    public scaling evidence; useful if implementation is quick, but less
    directly low-resource/South-African than HGRN2.
  - Griffin/RecurrentGemma: relevant local-attention + recurrence family, but
    public recipes are larger and less convenient for strict 125M from-scratch
    comparison.
  - RetNet/GLA-style retention or gated linear attention: useful literature
    context, lower priority unless there is an easy maintained implementation.
  - Byte-level/tokenizer-free variants: interesting for morphology and
    orthography, but likely a separate tokenizer/representation study rather
    than the next architecture slot.
- Papers/source trail to cite later:
  - MzansiText and MzansiLM: arXiv:2603.20732. Establishes the South African
    decoder-only baseline and says the authors were not aware of a public
    decoder-only model targeting all eleven official written South African
    languages.
  - Low-Resource Language Modelling of South African Languages: arXiv:2104.00772.
    Important caveat/ancestor: older South African architecture-style LM
    comparison, with well-regularized RNNs strongest on small datasets.
  - The State of Large Language Models for African Languages: Hussen et al.,
    PMLR DLI 2025/2026. Supports broader African low-resource coverage gap.
  - AfriqueLLM: arXiv:2601.06395. Recent African-language CPT study across
    several Transformer-family base models; useful related work but not a
    matched from-scratch efficient-architecture comparison.
  - Attention Is All You Need: arXiv:1706.03762, and LLaMA:
    arXiv:2302.13971 for the Transformer/LLaMA baseline.
  - Mamba: arXiv:2312.00752; Mamba-2/SSD: arXiv:2405.21060; Waleffe et al.
    Mamba empirical study: arXiv:2406.07887.
  - xLSTM: arXiv:2405.04517; xLSTM 7B: arXiv:2503.13427.
  - BabyHGRN: arXiv:2412.15978; HGRN2: COLM 2024/OpenReview.
  - RWKV: Findings EMNLP 2023 paper "RWKV: Reinventing RNNs for the
    Transformer Era."
  - RecurrentGemma/Griffin: arXiv:2404.07839.
  - RetNet: arXiv:2307.08621.
