### Exact-head-dimension repair and accepted canary

- Root cause was narrowed to the shared Transformers configuration/cache
  boundary. `xLSTMConfig.qk_dim` and `v_dim` rounded the 736-dimensional
  checkpoint to `384/768`, so `xLSTMCache` allocated per-head state
  `96/192`. Both the external xLSTM block and Transformers' layer projection
  logic use exact dimensions `int(hidden_size * factor)`, namely aggregate
