Root-Cause Read

  • xLSTM: usable representations are present. Generative failures on NER/SIB should be framed as objective/formulation failure, not blanket representation failure.
  • Mamba: weak head results persist after the fixed-runtime cleanup. This is less likely to be a missing-kernel/Hugging Face fallback artifact.
  • LLaMA: remains the stronger SIB classifier and decoder-only baseline, so keep the Transformer comparison as the main control.
  • GDN: still a staged hypothesis test. Evaluate only after real training starts: base loss, clean conditional loss, T2X source preservation, then matched task heads.
